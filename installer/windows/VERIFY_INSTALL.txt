Mozc AI インストール確認（GUI のみ・コマンド不要）
================================================

■ インストーラーが自動で行うこと

  1. 古い Mozc プロセスの停止
  2. Program Files (x86)\Mozc の削除（古い x86 版）
  3. Program Files\Mozc への 64-bit AI 版インストール
  4. ai_config.json の配置（クリーンインストール時は上書き）
  5. インストール検証結果の書き込み

  手動でのファイル削除やサーバー再起動は不要です。
  インストール後に PC を再起動してから、下記を確認してください。

■ 1. 正しいインストール先を確認

  Win + R キー → 次を貼って Enter:

    C:\Program Files\Mozc

  mozc_server.exe が存在すること。
  ※ 「Program Files (x86)\Mozc」にあるのは古い版です。
    AI 版は「Program Files\Mozc」（(x86) なし）に入ります。

■ 2. 自動検証結果を確認

  Win + R → 次を貼って Enter:

    %LOCALAPPDATA%\Google\Mozc

  install_verify.txt を開く。
  「RESULT: PASS」と表示されていればインストール成功。

■ 3. 動いている mozc_server を確認

  Ctrl + Shift + Esc → 詳細タブ
  mozc_server.exe を右クリック → ファイルの場所を開く

  正しい: C:\Program Files\Mozc\
  間違い: C:\Program Files (x86)\Mozc\

■ 4. ログ確認（再起動後に IME で入力してから）

  Win + R → 次を貼って Enter:

    %LOCALAPPDATA%Low\Mozc

  ai_log.txt / ai_alive.txt を開く。
  ※ mozc_server は Low Integrity のため、ログは LocalLow に出ます。
    （%LOCALAPPDATA%\Google\Mozc は設定用。ここにはログは書けません）

  「AIRewriter constructed」または「AIRewriter active」が出ていれば AI 動作中。

■ 5. DeepSeek 設定

  Win + R → %LOCALAPPDATA%\Google\Mozc
  ai_config.json で backend_type が deepseek であること。
  環境変数 DEEPSEEK_API_KEY をユーザー環境変数に設定済みであること。
