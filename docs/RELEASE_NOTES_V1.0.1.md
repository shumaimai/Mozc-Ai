# Mozc AI v1.0.1

v1.0.0 のローカルAI自動起動競合を修正した保守リリースです。

## 修正

- 旧WSL/personal版の `MozcAIRerank` 自動起動値をインストール時に削除
- 旧 `MOZC_RERANK_*` ユーザー環境変数を削除し、MSI同梱ランタイムの既定値へ統一
- 個人入力ログを有効化する `MOZC_RERANK_LOG` の残留を削除
- 旧AI設定テンプレートを外部API無効・通信ログ無効の安全な値へ変更
- MSI同梱の公開データ30Mモデル、推論ポリシー、Mozc統合コードはv1.0.0から変更なし

## 動作条件

- Windows 11 x64
- 推論先は `127.0.0.1:17890` のみ
- AIデーモン停止・エラー・200ms超過時はMozc本来の候補順を維持

## プライバシー

個人利用ログ、private usageモデル、APIキーは含みません。クラウド推論は使用しません。
