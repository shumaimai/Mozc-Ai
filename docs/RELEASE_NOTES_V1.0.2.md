# Mozc AI v1.0.2

Windowsログオン時にAIランタイムのコマンドプロンプトが表示される問題を修正した
保守リリースです。

## 修正

- `rerank_daemon.exe` をWindows GUIサブシステムでビルドし、コンソールを表示せず起動
- コンソールなし環境でも標準出力・標準エラーを安全に無効化
- ランタイムのビルド時smoke testを非表示プロセスとして実行

## 変更しないもの

- 公開データ30Mモデル、`tau=2.5`、推論ポリシー
- `127.0.0.1:17890`限定のローカル推論
- AI失敗・200ms超過時にMozc候補順を維持するフェイルセーフ
- 個人入力ログ・private usageモデル・外部APIを含めない方針
